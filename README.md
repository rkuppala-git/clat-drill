# CLAT Daily Drill

Daily vocabulary and GK practice for Avani's CLAT preparation. Installable on iPhone as a home-screen app and works offline.

## Publish on GitHub Pages (one time)
1. On github.com, create a new repository named `clat-drill` (Public).
2. Click **uploading an existing file**, drag in everything from this folder (including the `icons` folder), and click **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute or two the app is live at `https://<your-username>.github.io/clat-drill/`.

## Install on iPhone
Open that link in **Safari** → tap **Share** → **Add to Home Screen** → **Add**.

## Updating with new questions
Upload the new `index.html` and `sw.js` over the old ones (Add file → Upload files → Commit). The app picks up the update the next time it is opened online.
